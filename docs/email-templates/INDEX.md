# Tekmadev auth email templates

Generated by `build.mjs`. To use: in Supabase go to **Authentication > Emails > Templates**, open each template, set its **Subject**, and paste the file contents into the **Message body** (source/HTML).

| Supabase template | File | Subject |
|---|---|---|
| Confirm sign up | `auth/confirm-signup.html` | Confirm your email for Tekmadev |
| Invite user | `auth/invite.html` | Your Tekmadev client portal is ready |
| Reset password | `auth/reset-password.html` | Reset your Tekmadev password |
| Magic link or OTP | `magic-link.html` | Your Tekmadev sign-in link |
| Change email address | `change-email.html` | Confirm your new email address |
| Reauthentication | `reauthentication.html` | Your Tekmadev verification code |

The three `auth/` files are hand-written (not generated): their links use `{{ .RedirectTo }}?token_hash={{ .TokenHash }}&type=...`, which needs https://account.tekmadev.com/auth/confirm and https://www.tekmadev.com/admin/reset/confirm in **Authentication > URL Configuration > Redirect URLs**. Never use `{{ .ConfirmationURL }}` or a `{{ .SiteURL }}/admin/...` link for them.

Variables used: `{{ .RedirectTo }}`, `{{ .TokenHash }}`, `{{ .ConfirmationURL }}`, `{{ .Token }}`, `{{ .Email }}`, `{{ .NewEmail }}`.
`_preview-reset.html` is a sample-filled preview only, do not paste it into Supabase.
